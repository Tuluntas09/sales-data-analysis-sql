# Project Brief: Sales Data Analysis SQL

## Positioning

This repository is a finance-oriented SQL portfolio case study. It demonstrates
how raw commercial transaction data can be transformed into management-level
insights about revenue, profitability, margins, customer segments, discounts,
regional performance, and budget variance.

The project is designed for Financial Analyst, Finance Data Analyst, Business
Analyst, Junior Data Analyst, FP&A Analyst, Reporting Analyst, Revenue Analyst,
and BI Analyst roles.

## Business Problem

A fictional retail/e-commerce company wants to understand:

- Which products and categories generate the most revenue and gross profit.
- Whether high-revenue categories are also high-margin categories.
- Which customer segments and regions perform strongest.
- How discounts affect profitability.
- Whether monthly revenue and profit targets are being met.
- Which areas deserve management attention.

## Scope

The project includes:

- A five-table relational schema for customers, products, orders, order items,
  and monthly targets.
- CSV-based data import into PostgreSQL.
- Data quality checks before analysis.
- Reusable financial views for completed-order metrics.
- Analysis queries for revenue, margin, category, segment, region, discount,
  and budget performance.
- Management-style findings and companion Power BI dashboard support.

## Success Criteria

- SQL files can be run in a clear order from schema creation to analysis.
- Business metrics are calculated from reusable views rather than copied logic.
- Findings are stated in finance/business language, not only technical SQL terms.
- Documentation is readable by both technical reviewers and hiring managers.
